# Register onderzoeksdossiers

Eén regel per dossier: xref, naam, periode, status en de kernbevinding.

| xref | naam | periode | status | kernbevinding |
|---|---|---|---|---|
|  |  |  |  |  |

## Status-betekenis

- **afgerond** — alles is uitgezocht en vastgelegd; goedkeuring binnen.
- **loopt** — nog mee bezig.
- **wacht** — wacht op goedkeuring van pending changes in webtrees.
- **dood** — niets gevonden; noteer dat expliciet, zodat het niet opnieuw wordt uitgezocht.

> Voeg pas een regel toe als er een dossierbestand is. Houd dit register kort; de inhoud
> staat in `docs/onderzoek/<xref>-<naam>.md`.
